## Fixed comparisons and rounding

Let O(t) be the archived pre-2022 count and N(t) the current historical count for the same region/month. Retain the level revision N(t)-O(t) in ten thousand persons and relative revision N(t)/O(t)-1. Calculate three year-on-year growth values with exact rational arithmetic: archived coherent O(t)/O(t-12)-1; current coherent N(t)/N(t-12)-1; mixed N(t)/O(t-12)-1. The mixed series is an authored ingestion splice, not evidence that an actual organization made this error. The current coherent series is the reference for measuring that splice discrepancy, not ground truth for unobserved true employment.

Report archived-versus-current changes separately from mixed-versus-current discrepancies. Retain exact percentages, percentage-point discrepancies, absolute-error means/maxima, signed changes and each observation. Report sign disagreements including zero separately and strict opposite signs separately. Fixed descriptive alert thresholds are absolute growth at least 0.5% and 1%; these are illustrative, not calibrated operational cutoffs. Report both thresholds, all per-month mismatches and counts; do not select a winner or optimize a threshold on later results. No precision/recall against real hiring incidents is identifiable.

For a published rounded positive count x, use the conservative closed interval [x-0.5,x+0.5] in the native ten-thousand unit. For numerator a and denominator b>0.5, growth lies in [(a-0.5)/(b+0.5)-1,(a+0.5)/(b-0.5)-1]. These are rounding enclosures, not sampling or probabilistic confidence intervals. A positive/negative sign is certified only when the entire enclosure is strictly above/below zero. Otherwise mark rounding-ambiguous. A strict opposite-sign disagreement is rounding-robust only when both intervals certify opposite signs. For absolute-threshold classification, certify an alert only if the entire interval is beyond either signed cutoff, certify no alert only if strictly within both cutoffs, otherwise mark ambiguous. Never count ambiguity as a correct no-alert. Preserve published-point and rounding-certified results side by side. No stochastic independence, p-values, bootstrap confidence or causal inference claim.
