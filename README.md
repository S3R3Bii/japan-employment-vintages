# Compare employment on a consistent population base

An employment comparison can mix a revised current count with an older comparison count. That can change the apparent growth signal even when both numbers came from official tables. This study will compare two public versions of monthly employment estimates for Southern-Kanto and Kinki, Japan, and measure the effect of that splice.

**State: protocol before workbook capture.** No empirical finding, forecast, vacancy-demand estimate or operational benefit is established. These two monthly regional series are reference estimates with lower precision than national results. The [protocol](PROTOCOL.md) specifies the source, count definition, comparisons, rounding bounds and release checks.
